# Umbra 0.4.34

- Исправлено подключение панели к настольному клиенту после обновления 0.4.33.
  Из-за отсутствия аргументов запуска в защищённом preload панель ошибочно
  считала себя открытой в обычном браузере. Теперь доверенный адрес панели
  распознаётся и без этих аргументов.
- Вновь доступны запуск профилей, проверка прокси и смена IP из панели Umbra.
  Доступ к функциям клиента по-прежнему проверяется для главного окна и
  доверенного адреса при каждом вызове.

Состав движка и база данных не меняются. Cookies и локальные профили сохраняются.
