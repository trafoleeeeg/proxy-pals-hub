Минималистичный графитовый интерфейс Umbra.

- Нейтральная палитра без фиолетового декоративного акцента, единый оттенок оболочки и боковой панели, скруглённая рабочая область.
- Читаемые локальные шрифты, тонкие контурные иконки, спокойные кнопки, явный фокус при управлении с клавиатуры и поддержка уменьшения анимации.
- Сохранены сворачивание меню через логотип, навигация по разделам, перетаскивание и контекстные меню папок и профилей.
- Длинное боковое меню прокручивается, не сжимая пункты и блок учётной записи при раскрытой секции «Приложение».
- Колонки профилей получили читаемую ширину по умолчанию; пользовательские настройки остаются приоритетными, горизонтальная прокрутка ограничена таблицей.
- Общие цветовые токены включены в установленный клиент. Панель управления публикуется отдельно по прежнему адресу.

Обновление не меняет установленный движок, базу данных, права сотрудников, cookies или локальные данные профилей. Сборка установщика выполняется на GitHub Actions.
