Исправлено аварийное закрытие профиля после падения отдельной вкладки.

- Сбой renderer одной вкладки больше не завершает весь профиль.
- Обновление упавшей вкладки создаёт новый защищённый renderer и повторно применяет отпечаток до навигации.
- Закреплённая стартовая вкладка не перезапускается в обход защиты.
- Неожиданное отключение защиты живой страницы по-прежнему останавливает профиль безопасно.
