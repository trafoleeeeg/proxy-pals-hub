# Аварийный откат облачной синхронизации Umbra

## Цель
Вернуть загрузку панели и запуск профилей, не удаляя локальные зашифрованные cookies, прокси и данные профилей.

## Изменения
1. Убрать автоматические Realtime-подписки настроек браузера и рабочего пространства из критического пути запуска панели. Закладки, масштаб и закреплённые расширения продолжат загружаться при открытии профиля, но временно не будут мгновенно синхронизироваться между уже открытыми компьютерами.
2. Разорвать конфликт авторизации: обработчик входа/выхода не будет запускать повторную проверку сессии внутри события авторизации. Обновление панели будет отложено до освобождения блокировки сессии.
3. Сделать локальную очередь закрытия неблокирующей для всей панели. Сбой одной старой записи будет показан только у соответствующего профиля; загрузка рабочего пространства и остальные профили останутся доступны.
4. Для окончательно устаревшей блокировки сохранить зашифрованный снимок только в локальном архиве и прекратить бесконечные повторы. Cookies не удаляются и не раскрываются.
5. Добавить проверки сценариев: зависшая авторизация, одна старая запись очереди, загрузка рабочего пространства при отключённой Realtime-синхронизации и запуск другого профиля.

## Проверка
- Лёгкие тесты панели и жизненного цикла профилей.
- Проверка TypeScript и синтаксиса Electron-файлов.
- Проверка в опубликованной панели: вместо вечной загрузки открывается рабочее пространство либо предлагается повторный вход.

## Ограничение
Это откат только фоновой мгновенной синхронизации. Облачную схему и сохранённые данные не откатываем, чтобы не потерять профили и настройки.
