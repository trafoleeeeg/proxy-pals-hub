Исправлена ложная защитная остановка профиля при обновлении фонового worker сайта.

- Chromium сообщает `Inspector.targetCrashed` и при штатном завершении заменённой версии service worker. Umbra теперь проверяет её статус и подтверждение окончательного завершения; обычная замена версии не закрывает профиль.
- Принятая команда остановки больше не считается доказательством завершения worker. Поздние ответы от уже уничтоженного процесса не закрывают профиль повторно.
- Устаревшая настройка worker не может возобновить его новый экземпляр раньше завершения защиты.
- Добавлены проверки повторных обновлений worker, двух профилей, сохранения cookies и хранилищ, повторного открытия и перезапуска приложения.

Защитная остановка при неподтверждённом завершении, потере управляющего канала или небезопасном перезапуске прежнего worker сохраняется. Это исправление штатного обновления сайта, не замена движка. Сборка установщика выполняется на GitHub Actions.
