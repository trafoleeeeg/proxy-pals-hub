# Umbra 0.4.49

- Исправлено зависание восстановления панели, когда общий индикатор сети уже сброшен, но сама страница ещё не восстановилась.
- Технический журнал теперь сохраняет полный Windows-код аварийного завершения, включая беззнаковые NTSTATUS.
- Добавлены ограниченные технические признаки фатальной ошибки и причины потери внутреннего канала. Текст страниц, cookies, токены и содержимое памяти не записываются и не отправляются.
- В журнале теперь учитывается переход на встроенную панель при ошибке загрузки её локального пакета.

Это обновление улучшает диагностику полного закрытия приложения. Конкретная причина ранее произошедшего падения ещё не установлена; данный выпуск не объявляется исправлением этого падения.

Движок не меняется. Профили и их локальные данные сохраняются. Обновление устанавливается при обычном завершении работы приложения, без принудительного закрытия активных профилей.
