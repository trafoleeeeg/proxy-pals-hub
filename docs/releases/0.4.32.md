# Umbra 0.4.32

- Добавлена экспериментальная изоляция шрифтов: отдельный фиксированный набор
  Arimo, Tinos и Cousine вместо установленных на ПК шрифтов. Режим выключен
  по умолчанию; включается при создании и редактировании профиля. После смены
  режима у ранее запущенного профиля нужно перезапустить Umbra.
- Согласованы сообщаемые CPU/RAM между страницами, iframe, workers и
  заголовками запросов. Согласованы ориентация и цветовые CSS-параметры экрана.
- Убрана частичная подмена разрешённых Canvas/Audio/GPU API, которая создавала
  противоречия и искажала данные. Строгие запреты без исключений сохранены.
- Проверяется целостность комплекта шрифтов; при отсутствии защиты профиль
  не запускается. Исключение сайта не открывает доступ к шрифтам ПК в режиме
  изоляции.

Ограничения: фиксированный набор не имитирует стандартные шрифты Windows;
вид сайтов может измениться, часть символов и emoji может отсутствовать.
GPU и аудиоустройство не эмулируются. Разрешённые аппаратные API и растеризация
могут раскрывать характеристики машины. PDF/печать и несколько физических
мониторов/DPI не покрыты полной проверкой. Нераспознаваемость не гарантируется.

Cookies, профили и база данных при обновлении не сбрасываются.
