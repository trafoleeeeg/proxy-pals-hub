# Chrome-подобная панель и окно профиля

## Что изменится
- Привести веб-панель к плотному Chrome Graphite виду: системный шрифт, компактные отступы и радиусы, спокойные границы и единая тонкая прокрутка без лишних теней.
- Зафиксировать панель на высоту окна и перенести прокрутку внутрь основной области, чтобы боковое меню оставалось на месте.
- Обновить верхнюю часть окна профиля по выбранному варианту: привычная полоса вкладок, плюс сразу после последней вкладки, компактная навигация и действия справа от адресной строки.
- Добавить отдельную кнопку «Закладки», открывающую полноразмерный диспетчер внутри окна профиля.
- В диспетчере реализовать поиск, добавление, редактирование, удаление, открытие и перетаскивание закладок; изменения сохраняются в локальном зашифрованном хранилище текущего профиля.
- Переделать меню масштаба в одну Chrome-подобную строку с кнопками минус/плюс и текущим процентом.
- Оформить поиск по странице как компактную Chrome-панель с лупой, счётчиком результатов и навигацией.

## Технические детали
- Сохранить sandbox, contextIsolation, изоляцию partition, сетевую блокировку оболочки и fail-closed proxy без изменений.
- Расширить локальные команды закладок безопасным изменением порядка и передавать актуальный масштаб активной вкладки в оболочку.
- Добавить и обновить автоматические тесты для команд, состояния масштаба и управления закладками.
- Не менять версию 0.4.6, не создавать тег, релиз или установщик.

## Проверка
- Запустить лёгкие тесты, проверку синтаксиса и TypeScript локально.
- Полный нативный Electron-набор и Windows-сборку запускать только через GitHub Actions, без публикации Release.
