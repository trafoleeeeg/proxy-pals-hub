# Полный доступ для агентов (Claude, Codex, Astra) без конфликтов

Цель: агенты могут и править код, и работать с данными Umbra — параллельно со мной,
не ломая друг другу работу.

## Часть 1. Код — правила неконфликтной работы

Доступ к коду уже есть через GitHub. Чтобы правки не били друг друга:

- Каждый агент работает в своей ветке: `agent/claude/<задача>`, `agent/codex/<задача>`,
  `agent/astra/<задача>`. В `main` попадает только через Pull Request.
- Автопроверка на каждый PR (новый workflow): установка зависимостей, проверка типов,
  проверка файлов Electron. Сломанный PR нельзя влить.
- Защита ветки `main`: запрет переписывания истории, обязательная зелёная проверка.
- Расширение AGENTS.md: раздел «как не конфликтовать» — не трогать `desktop/package.json`
  версию без нужды, не править одновременно одни и те же файлы, не делать force push.

## Часть 2. Данные — API для агентов с ключами

Новая таблица `agent_keys`: имя агента, хеш ключа, права, команда, срок, отзыв.
Ключ показывается один раз при создании, в базе хранится только его хеш.

Права выдаются галочками: `profiles:read`, `profiles:write`, `proxies:read`,
`proxies:write`, `team:read`. Права на управление командой агентам не выдаём.

Адреса (под `/api/public/agent/`, каждый проверяет ключ и права):

| Действие | Адрес |
| --- | --- |
| Кто я, какие права | `GET /api/public/agent/me` |
| Список профилей | `GET /api/public/agent/profiles` |
| Создать профиль | `POST /api/public/agent/profiles` |
| Изменить/удалить профиль | `PATCH`/`DELETE /api/public/agent/profiles/:id` |
| Список прокси | `GET /api/public/agent/proxies` |
| Добавить прокси | `POST /api/public/agent/proxies` |

Защита: пароли прокси и cookies наружу не отдаются никогда. Ограничение частоты
запросов. Каждое действие пишется в журнал `audit_log` с именем агента.

## Часть 3. Экран управления ключами

Новая вкладка «Агенты» в панели (доступна только владельцу):
создать ключ, увидеть его один раз, посмотреть список, отозвать, посмотреть
последние действия агента.

## Часть 4. Подключение агентов

Файл `agents/README.md` с готовой инструкцией: как склонировать код, как
подключить ключ, примеры запросов. Claude и Codex читают её сами.

## Технические детали

- Ключ: `umbra_live_` + 32 случайных байта; в базе — SHA-256 хеш, сравнение
  через `timingSafeEqual`.
- Роуты — TanStack server routes под `src/routes/api/public/agent/`, проверка
  ключа в общем хелпере `src/lib/agent-auth.server.ts`, записи в БД через
  `supabaseAdmin`, загружаемый внутри обработчика.
- Миграция: `agent_keys` (+ `GRANT`, RLS: читает и меняет только владелец команды),
  индекс по хешу ключа.
- Workflow `.github/workflows/ci.yml`: `bun install`, `bunx tsgo --noEmit`,
  `node --check` для файлов `desktop/`.
- Защиту ветки `main` и доступ соавторам настраиваю через GitHub API.
