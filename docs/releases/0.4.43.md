Бесшовный запуск Umbra и восстановление панели после простоя.

- Основное окно показывается без ожидания сети. Внутри него появляется локальный каркас интерфейса без данных аккаунта; панель загружается параллельно.
- Убрана последовательная загрузка локальной заставки и второй заставки веб-панели. Готовый интерфейс появляется в том же окне после отрисовки маршрута.
- Повторные запуски используют обычную HTTP-проверку кэша и сохранённые статические ресурсы вместо случайного адреса и принудительного обхода кэша.
- Сетевые попытки запуска ограничены по времени. Закрытие во время загрузки отменяет дальнейший запуск и освобождает временный слой.
- В веб-панели временные ошибки сети и сервера авторизации больше не считаются недействительными учётными данными. Запросы авторизации ограничены по времени; восстановление связи работает после возвращения сети и выхода из фона.
- Уязвимые зависимости веб-панели seroval и source-map-js обновлены.

Холодный запуск движка, проверка входа и получение данных по сети всё ещё требуют времени; мгновенная полная готовность не гарантируется. Проверка входа, права, sandbox и защита профилей не отключаются ради скорости. Движок остаётся на проверенной версии Electron 44.4.5 с существующими нативными патчами; новой компиляции Chromium и миграции базы не требуется.

Установка обновления выполняется штатно, после закрытия профилей. Локальные данные профилей сохраняются.
