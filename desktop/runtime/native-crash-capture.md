# Локальная диагностика нативного падения

По умолчанию сбор минидампов выключен. Нужны явное согласие владельца
компьютера и локальный файл `userData/diagnostics/native-crash-capture.json`:

```json
{
  "enabled": true,
  "directory": "D:/private/umbra-native-crashes",
  "expiresAt": 1792180496000
}
```

`expiresAt` — будущий Unix timestamp в миллисекундах, не дальше семи дней.
Папка должна существовать, находиться на локальном диске, без junction/symlink,
и называться `umbra-native-crashes`. Перед включением ограничить её Windows ACL
владельцем, SYSTEM и администраторами. Веб-панель не может включать сбор.

Crashpad запускается до supervisor и создания окон, отдельно для координатора
и браузерного процесса. `uploadToServer: false`, адрес отправки отсутствует;
пользовательские аннотации не передаются. **Сам минидамп может содержать
чувствительные фрагменты памяти сессий. Его нельзя прикладывать к PR, отправлять
на GitHub или выводить целиком в журнал/чат.**

На старте и раз в минуту удаляются только старые UUID `.dmp`/связанные `.meta`
в собственной папке Crashpad: сохраняются три последних отчёта каждого процесса,
ориентир 128 MiB и семь дней. Самый свежий и файлы моложе двух минут сохраняются
всегда; заблокированные файлы остаются до следующего прохода. Это best-effort
retention, а не жёсткая квота. База Crashpad и посторонние файлы не удаляются.

Истечение согласия/удаление локального файла прекращает включение сбора при
следующем запуске. Electron не позволяет выключить уже запущенный Crashpad без
перезапуска процесса. Оставшиеся отчёты автоматически не отправляются.

Для первичной диагностики использовать
`node desktop/scripts/summarize-minidump.cjs <local-dump-path>`: читаются только
метаданные исключения и модуля, без потоков памяти, командной строки и аннотаций.
Для определения функции нужен локальный debugger и PDB, совпадающий по GUID/age
с упавшим модулем. Наличие диагностики не является исправлением причины падения.

Нативный тест намеренно падает только в отдельном процессе с временными данными.
Он проверяет реальный локальный `.dmp` и запрет загрузки; рабочие профили не открывает.
