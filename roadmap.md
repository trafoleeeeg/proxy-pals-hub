# Roadmap

- [x] Объединить все данные в одну команду Umbra без потери профилей, папок, прокси и настроек.
- [x] Оставить `mafiatrafa@umbra.app` единственным владельцем с полными правами.
- [x] Удалить лишние команды и старые членства после переноса данных.
- [x] Добавить суперадминистратору изменение логина, имени и пароля сотрудника.
- [x] Проверить выдачу и отзыв прав сотрудников и доступов к папкам.
- [x] Проверить итог под `mafiatrafa@umbra.app`.
- [x] Восстанавливать изображения и стили открытых страниц после смены или автоматического переключения прокси.
- [x] Автоматически восстанавливать вкладку при серии сетевых сбоев изображений, стилей и шрифтов.
- [x] Исключить фотографии и крупные Canvas-элементы из подмены пикселей отпечатка.
- [x] Показывать меню и всплывающие панели поверх снимка страницы, не сдвигая содержимое вниз.
- [x] Сохранять значки сайтов между запусками профиля.
- [x] Заранее открывать соединение с сайтом при вводе адреса и наведении на закладку.
- [x] Перезагружать повреждённую страницу без сброса кэша.
- [x] Поддержка букмарклетов (javascript:) в закладках; букмарклет «lark bot» в стартовом наборе.
