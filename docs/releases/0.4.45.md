Исправление загрузки рабочего пространства во встроенной панели.

- Исправлен отказ `403 Forbidden` при пересылке запросов серверных функций через Electron: сохранение токена авторизации само по себе не сохраняло служебные CSRF-заголовки Chromium.
- Заголовки восстанавливаются только для запросов к серверным функциям собственной панели с подтверждённым нативным origin инициатора. Запросы неизвестного, стороннего и opaque-источника отклоняются; CSRF и проверка токена на сервере остаются включены.
- Добавлен нативный HTTPS-тест реального сетевого моста с фиктивным токеном, проверкой тела запроса и отрицательной проверкой sandboxed iframe. Тесты не используют аккаунты пользователей или их cookies.

Движок, права доступа, база и содержимое профилей не изменяются. Для установки штатно закройте профили и Umbra. Настройки установщика сохраняют локальные данные.
