# Umbra 0.4.33

- Исправлен обнаруженный обход прокси спекулятивными DNS-запросами страниц:
  движок больше не передаёт renderer DNS-prefetch в системный resolver.
  Защита действует также во вложенных документах, при наведении на ссылки
  и для HTTP Link hints. Обычная загрузка сайтов через прокси сохранена.
- При создании и изменении параметров памяти доступны значения 2, 4 и 8 ГБ.
  Старые профили автоматически не переписываются; несовместимое значение
  потребуется явно исправить при изменении отпечатка или копировании профиля.
- Расширены регрессионные проверки отказа прокси, WebSocket, STUN, IPv6,
  TURN и DNS. Новый движок закреплён и проверяется по SHA-256.

DNS-prefetch отключён во всех сессиях движка, включая режим без прокси:
это может немного замедлить первое подключение к сайту.

Ограничения: проверка внешнего IPv6 и TURN UDP6 остаётся неполной;
полный TURN-медиасеанс не проверен. GPU, Canvas и аудиоустройство не
эмулируются: разрешённые API могут раскрывать характеристики машины.
Обновление не гарантирует отсутствие всех утечек или нераспознаваемость.

Cookies, профили и локальные данные при обновлении не сбрасываются.
Миграций базы данных нет.
