# Umbra 0.4.37

Исправлено закрытие всего окна профиля при нажатии Ctrl+W.

- Ctrl+W закрывает только активную обычную вкладку, включая русскую раскладку и фокус в адресной строке.
- Закреплённая стартовая страница остаётся открытой; после закрытия обычной вкладки выбирается соседняя.
- Штатное закрытие вкладки больше не может ошибочно блокировать общую сессию профиля как потерю защиты.

Изменения проверены тестами горячих клавиш и нативным сценарием закрытия вкладок на Windows.
