# Облачная синхронизация профиля Umbra

## Что будет сделано

- Перенести в Lovable Cloud настройки каждого профиля:
  - закладки и их порядок;
  - видимость панели закладок;
  - масштаб страниц;
  - список синхронизируемых расширений и их закрепление на панели.
- Не синхронизировать cookies, открытые вкладки, прокси-пароли и локальные файлы расширений.
- При запуске профиля загружать актуальные настройки из облака и сохранять локальную копию для работы при временной потере связи.
- Передавать изменения из окна профиля в авторизованную панель, а оттуда — в облако.
- Автоматически получать изменения, сделанные на другом компьютере, и обновлять открытое окно профиля без ручного перезапуска.

## Безопасность и правила доступа

- Добавить новую миграцию, не изменяя существующие миграции.
- Доступ к настройкам ограничить текущей командой и правами на конкретный профиль через RLS.
- Запись разрешить владельцу профиля; участникам команды оставить только допустимый правилами проекта доступ.
- Синхронизировать только безопасные данные расширения: адрес источника, идентификатор и признак закрепления. Код расширения будет повторно скачиваться с HTTPS-источника; расширения, добавленные из локальной папки, останутся только на текущем компьютере.
- Проверять размеры, адреса, идентификаторы и версии данных до сохранения и применения.

## Изменения клиента и панели

- Добавить серверные функции чтения и атомарного сохранения настроек профиля.
- Расширить данные запуска профиля начальными облачными настройками.
- Добавить защищённые события между окном профиля и панелью:
  - локальное изменение → сохранение в облако с короткой задержкой;
  - облачное изменение → применение в открытом профиле;
  - защита от циклического повторного сохранения и устаревших ответов.
- Сохранять масштаб при каждом изменении и применять его к новым и уже открытым вкладкам.
- После облачного обновления сразу перерисовывать панель закладок и закреплённые расширения.

## Проверка

- Добавить тесты нормализации данных, конфликтов версий, закладок, масштаба, закрепления и событий синхронизации.
- Выполнить лёгкие локальные проверки синтаксиса и типов без тяжёлого Electron-прогона.
- После синхронизации с GitHub запустить `workflow_dispatch`: полный Linux Electron suite и Windows-сборку версии 0.4.6 без создания нового Release.
- Проверить состав временного Windows-артефакта. Установить его на физический Windows-компьютер из этой среды невозможно; установка и визуальная проверка на реальной вкладке потребуют запуска полученного EXE на вашем компьютере.

## Технические детали

- Новая облачная запись настроек будет иметь монотонную ревизию/время обновления для разрешения конфликтов между компьютерами по принципу «последнее подтверждённое изменение».
- Для открытого профиля панель будет периодически проверять облачную ревизию и применять только более новую; локальные изменения отправляются через IPC только доверенному окну панели.
- Имеющаяся локальная зашифрованная копия останется резервом и будет обновляться после успешного применения облачного состояния.
