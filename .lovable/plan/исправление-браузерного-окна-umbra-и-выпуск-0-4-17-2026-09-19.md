# Исправление браузерного окна Umbra и выпуск 0.4.17

## Что изменю
- Переделаю окна расширений в компактные нативные popup, привязанные к значку: корректный размер, фокус, клики, прокрутка и закрытие как в Chrome.
- Нормализую значки расширений: правильный файл из manifest, одинаковый размер и чёткое отображение на панели и в списке.
- Уберу задержки вкладок и ссылок: мгновенно показывать/скрывать вкладку, не ждать сохранения cookies при закрытии, не блокировать быстрые команды длинными операциями, сократить лишние перерасчёты окна.
- Сохраню защиту профиля: sandbox, отдельную partition, fingerprint до загрузки сайта и fail-closed proxy.
- Добавлю проверки для переключения/закрытия вкладок, открытия ссылок и popup расширений.
- Включу уже готовое редактирование и удаление статусов профилей.

## Проверка и выпуск
- Запущу лёгкие проверки JavaScript/TypeScript и desktop-тесты без тяжёлой локальной Electron-сборки.
- Выпущу версию 0.4.17 через GitHub Actions для Windows и опубликую установщик с автообновлением.

## Технические детали
- Popup расширения будет использовать сессию конкретного профиля, но отдельное безопасное окно без Node.js.
- Закрытие вкладки сначала обновит интерфейс, а сохранение сессии выполнится асинхронно; закрытие всего профиля по-прежнему дождётся сохранения.
- Состояние панели будет обновляться только при реально изменившихся данных, без повторной раскладки всех страниц на каждое событие загрузки.
