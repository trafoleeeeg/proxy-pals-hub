# Desktop-проверка в GitHub Actions

## Что изменю
- Доработаю существующий `.github/workflows/desktop-windows.yml`, не создавая дубликат.
- Оставлю ручной запуск через `workflow_dispatch` и разделю проверку на два независимых задания:
  - Linux: системные библиотеки Electron, виртуальный экран, полный набор `desktop/test/*.test.cjs`, проверки синтаксиса и TypeScript.
  - Windows: существующая упаковка `npm run build:win` без публикации Release, загрузка результата только во временный Actions artifact.
- Для ручного запуска полностью исключу задание публикации; выпуск по тегам не буду запускать или изменять в рамках этой задачи.
- Установлю ограниченный срок хранения artifacts и дам Linux/Windows заданиям отдельные имена и логи.

## Проверка
- Проверю синтаксис workflow и неизменность версии `0.4.4` локально, без тяжёлого Electron-прогона и desktop-сборки в Lovable.
- Запущу workflow вручную через подключённый GitHub, дождусь обоих заданий и изучу логи при ошибках.
- При ошибках кода или workflow внесу исправления и повторю запуск до зелёного результата.

## Ограничения
- Не создавать тег, GitHub Release и опубликованный установщик.
- Не менять настройки безопасности Electron, профилей и прокси.
- Не добавлять Linux-библиотеки в `package.json`.
